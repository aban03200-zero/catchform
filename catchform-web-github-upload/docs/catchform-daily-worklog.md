# CatchForm Daily Worklog

이 파일은 CatchForm 작업 중 변경한 내용을 날짜별로 기록하는 문서입니다.
앞으로 기능 수정, 배포 준비, 오류 수정, 성능 개선이 생기면 같은 형식으로 이어서 남깁니다.

## 2026-06-05

### 반영 내용

- 스팩스페이스 소속 폼 제출 시 `applications.brand`에 `SFACSPACE`가 그대로 들어가 DB 외래키 오류가 발생하던 문제를 수정
- 운영 폼과 프레이머 임시 운영본 모두 제출 저장 payload의 브랜드 값을 레거시 DB 호환 값으로 정규화해 저장하도록 변경
- 화면/관리자 분류용 실제 브랜드 값은 계속 `config.brand = SFACSPACE`로 유지되며, 응답 저장용 FK 컬럼만 호환 값으로 저장됨
- 폼 휴지통에 `영구 삭제` 버튼을 추가해 휴지통에 들어간 폼의 제출 응답, QR/분석 이벤트, 폼 설정을 완전히 삭제할 수 있도록 변경
- `교육과정 신청폼` 템플릿을 별도 KDT 렌더러가 아닌 일반 폼 렌더러 구조로 변경하고, 기존 `kdt` 저장본도 불러올 때 일반 폼 구조로 변환되도록 보강
- `교육과정 신청폼`의 제출 저장 `application_type`을 더 이상 `kdt`로 묶지 않고, 편집 화면의 `지원 유형` 값에 따라 `pre` 또는 `formal`로 저장되도록 변경
- QR 리다이렉트와 폼 진입 이벤트에 `cf_form_id`를 포함해 교육과정 신청폼의 QR 스캔/방문 데이터가 분석 화면에서 같은 폼으로 집계되도록 보강
- 스나이퍼팩토리 브랜드 폼 로그인 시 사용자가 입력한 이메일은 그대로 두고, Supabase Auth 로그인 요청에만 `.sniperfactory` suffix가 붙은 내부 이메일로 변환되도록 변경
- 인사이드아웃과 스팩스페이스 브랜드 폼 로그인은 기존처럼 입력 이메일 그대로 Supabase Auth에 전달되도록 유지
- 스나이퍼팩토리 폼 링크와 QR 리다이렉트가 `NEXT_PUBLIC_SF_FORM_BASE_URL` 대신 `https://catchform.vercel.app/form/{slug}` 직접 링크를 사용하도록 변경
- `NEXT_PUBLIC_SF_FORM_BASE_URL`을 더 이상 필수 환경변수로 안내하지 않도록 관리자 환경변수 안내 문구와 배포 문서를 정리
- 선택형 질문 응답 저장 시 내부 option value가 아니라 사용자에게 보이는 option label을 저장하도록 변경
- 분석표, 질문별 차트, CSV 내보내기에서 기존 응답의 내부 value도 현재 옵션 label로 매핑해 표시하도록 보강
- 응답 시트 다운로드 CSV에서 자동으로 붙던 이름, 전화번호, 이메일 컬럼을 제거하고 날짜, 시간과 폼에 실제로 있는 질문 항목만 내보내도록 변경
- 관리자 설정 모달 이름을 `폼 설정`으로 바꾸고, 모달 안에서 폼 제목을 수정해 `form_configs.name`에 저장할 수 있도록 변경
- 폼 설정의 운영 기간에 `상시 운영` 체크박스를 추가하고, 체크 시 시작/종료일 없이 대시보드 상태가 진행중으로 표시되도록 변경
- 폼 설정에서 `기간 미설정 시 상태` 드롭다운을 제거하고, 새 저장본은 기간 또는 상시 운영 설정으로만 상태를 계산하도록 정리
- `상시 운영`을 켰다가 꺼도 기존 운영 시작/종료일이 보존되도록 변경하고, 실제 공개 폼에서는 `alwaysOpen`일 때 저장된 기간을 무시하도록 보강
- 스팩스페이스 폼 제출 시 `applications.brand`가 `SFACSPACE`로 저장되도록 공개 폼 제출 payload를 변경
- 참여기업/회사형 폼 응답은 템플릿 복제 후에도 `company_applications` 테이블로 저장·조회되도록 폼 타입과 회사형 필드 기반 판별을 보강
- 응답별 데이터 표에서 긴 단답형/장문형 응답은 셀 안에서 줄바꿈되도록 하고, 복수 선택 응답은 세로 목록으로 표시되도록 변경
- 새 질문 추가 시 단답형/장문형 placeholder와 선택형 기본 예시 옵션이 자동으로 생성되도록 변경
- 새 폼 저장 및 폼 복제 시 제목 기반 한글 슬러그 대신 안전한 숫자 조합 슬러그를 자동 생성하도록 변경
- 교육과정 연동 폼에서 운영 기간 기준을 `사전 모집 기간` 또는 `정식 모집 기간` 중 선택할 수 있도록 추가하고, 선택 기준을 공개 폼 기간 병합에 반영
- 응답별 데이터 표에서 단답형/장문형 응답 컬럼의 기본 너비를 기존 일반 컬럼의 2배로 넓히고, 해당 컬럼만 헤더 우측 핸들 드래그로 가로 너비를 조절할 수 있도록 변경
- 참여기업/회사형 폼의 기존 응답이 `applications`에 남아 있고 새 응답이 `company_applications`에 쌓이는 경우에도 응답별 데이터에서 두 테이블을 합쳐 보여주도록 변경
- 교육과정 연동의 폼 운영 기간 기준 선택 UI에서 `현재 기준` 요약 박스를 제거하고, 모집 기간 날짜/시간 표기를 초·타임존 없는 간결한 형식으로 정리

### 확인 필요

- 스팩스페이스 폼 제출 후 완료 모달이 정상 표시되는지 확인
- 관리자 대시보드에서는 해당 폼이 계속 스팩스페이스 그룹에 남아 있는지 확인
- 폼 휴지통에서 영구 삭제한 폼은 제출 응답과 분석 이벤트까지 복구할 수 없음
- 교육과정 신청폼을 새로 만들면 `지원 유형`에서 사전 알림/정식 신청을 선택할 수 있고, 제출 row의 `application_type`도 선택값으로 저장됨
- 기존 교육과정 신청폼은 편집 또는 운영 렌더링 시 일반 폼 구조로 변환되어 표시됨
- 스나이퍼팩토리 로그인 필수 폼에서 `user@example.com`으로 입력하면 내부 로그인 요청은 `user@example.com.sniperfactory` 계정으로 처리됨
- Vercel의 `NEXT_PUBLIC_SF_FORM_BASE_URL`은 코드에서 더 이상 읽지 않으므로 삭제해도 되며, 삭제 후에는 새 배포가 한 번 반영되어야 함
- `신입`/`경력`처럼 label과 value가 다른 선택형 응답도 분석표에서는 사용자가 선택한 label로 표시됨
- 응답 시트 다운로드 파일에는 날짜, 시간과 폼 편집 화면에 있는 질문 항목만 헤더로 포함됨
- 폼 설정에서 제목을 바꾸면 대시보드 목록과 현재 편집 중인 폼 이름이 함께 갱신됨
- 프로그램 DB 모집 기간이 없는 폼은 `상시 운영`을 켜면 기간 입력 없이 진행중으로 표시되고, 끄면 기간이 없을 때 작성중으로 표시됨
- 스팩스페이스 제출이 성공하려면 Supabase `brands`/FK 기준에도 `SFACSPACE` 값이 허용되어 있어야 함
- 프로그램 DB의 사전 모집 기간 컬럼명이 코드의 후보 키와 다르면 `기간 데이터 없음`으로 표시될 수 있으므로 실제 컬럼명 확인 필요
- 응답별 데이터 표의 단답형/장문형 질문 헤더 우측 가장자리를 드래그하면 컬럼 폭이 조절되고, 다른 질문 유형 컬럼은 기존 폭으로 유지됨
- 참여기업 모집 폼에서 응답 수가 0으로 보였던 기존 `applications` 응답도 같은 폼 ID 기준으로 함께 표시되며, 응답 수정/삭제는 각 응답이 원래 저장된 테이블에 적용됨

- 로그인 후 폼 리스트는 전체 페이지가 아니라 테이블 영역만 스크롤되도록 바꾸고, 테이블 헤더를 상단에 고정하도록 변경

- 편집 비밀번호가 설정된 폼은 휴지통으로 이동할 때도 편집 비밀번호를 입력해야 삭제가 진행되도록 보강
- 폼 편집 속성창에서 답변 옵션 손잡이를 드래그할 때 부모 질문 드래그 이벤트로 전파되어 속성창이 닫히던 문제를 수정
- 답변 옵션 드래그가 취소되거나 완료된 뒤에도 질문 행이 비활성화된 것처럼 흐리게 남지 않도록 드래그 상태 정리 로직을 보강
- 답변 옵션 정렬을 위/아래 버튼 방식에서 손잡이 드래그 앤 드롭 방식으로 변경

- 슬러그 설정 패널에 한글, 공백, 특수문자를 사용할 수 없다는 안내 캡션을 추가
- 슬러그 저장 시 영문, 숫자, 하이픈 외 문자가 들어가면 저장을 막아 한국어 슬러그로 폼 렌더가 깨지지 않도록 보강

### 확인 필요

- 운영 기간이 설정되지 않은 폼은 기존처럼 기간 차단 없이 동작함
- 기간이 종료된 폼은 입력 화면 진입은 가능하지만 신청 진행과 제출은 막히며, `모집이 종료되었습니다.` 안내가 표시됨
- 편집 비밀번호는 보안을 위해 원문을 저장하지 않으므로 복구할 수 없고, 분실 시 `master` 권한 계정이 초기화한 뒤 새 비밀번호를 다시 설정해야 함
