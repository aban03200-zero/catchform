# CatchForm Daily Worklog

이 파일은 CatchForm 작업 중 변경한 내용을 날짜별로 기록하는 문서입니다.
앞으로 기능 수정, 배포 준비, 오류 수정, 성능 개선이 생기면 같은 형식으로 이어서 남깁니다.

## 2026-05-28

### 반영 내용

- Google Apps Script 시트 전송을 브라우저 직접 호출에서 Next.js 서버 API(`/api/google-sheets`) 경유 방식으로 변경
- 폼 제출 후 `script.google.com` JSON 응답 화면이 새 창/현재 창에 노출될 수 있는 경로를 제거
- Framer처럼 Next API가 없는 환경에서는 숨은 iframe/form 제출 대신 `no-cors` fetch로만 전송하도록 fallback 변경

### 확인 필요

- Vercel 재배포 후 폼 제출 시 성공 모달만 뜨고 Apps Script JSON 화면이 열리지 않는지 확인

## 2026-05-27

### 반영 내용

- 루트 페이지(`/`)를 임시 랜딩 대신 관리자 로그인 화면(`/admin`)으로 바로 이동하도록 변경
- 웹 내부에서 굵게 표시되던 `fontWeight: 700/800/900`, `font-weight: 700/800` 계열 스타일을 세미볼드(`600`)로 정리
- 실제 폼 URL(`/form/[slug]`)에서 서버가 먼저 `form_configs`의 `id, config`를 가져와 폼 컴포넌트에 전달하도록 변경
- 브라우저에서 폼을 다시 열 때 `sessionStorage` 캐시를 먼저 사용하고, 백그라운드에서 최신 config를 갱신하도록 변경
- 관리자에서 폼 편집/복사 시 같은 폼 config를 반복 조회하지 않도록 상세 config 메모리 캐시 추가
- 기간별 인사이트의 공유 지표 문구를 `유니크`에서 `중복 제외`로 바꾸고 설명 문구를 쉽게 정리
- 위치 데이터의 `미확인` 기준 설명을 보강
- 대시보드에서 폼 목록이 열린 뒤 주요 폼 config를 미리 불러오고, 폼 hover 시에도 상세 config를 선조회하도록 편집 로딩 개선
- 기간별 인사이트의 일자별 응답 수를 프로그래스바 목록에서 막대 그래프로 변경
- 분석 그래프 색상을 선명한 원색에서 파스텔톤 팔레트로 조정
- 응답 및 분석 탑바에 응답 전체 삭제 버튼과 새로고침/삭제 툴팁 추가
- 응답 전체 삭제 시 확인 모달을 띄우고, 해당 폼의 응답 row와 분석 이벤트를 함께 삭제하도록 추가
- 유입경로 도넛 그래프를 둥근 끝점이 있는 arc 방식으로 변경
- 위치 분석에 country 외 region/city metadata를 반영하고, 대한민국 지역 단위 표시를 추가
- 질문별 이탈률 관련 아이콘을 이탈 의미가 더 직관적인 아이콘으로 변경
- Google Apps Script 시트 전송을 숨은 iframe/form 방식에서 `fetch` 전송으로 바꿔 제출 후 JSON 탭이 뜨는 문제를 방지

### 확인 필요

- Vercel 재배포 후 `/admin` 접속 시 로그인 화면으로 바로 이동하는지 확인
- 실제 운영 폼 URL(`/form/슬러그`)에서 첫 로딩 체감 속도 확인
- Supabase에서 폼 수정 직후 운영 페이지 반영은 최대 30초 캐시가 있을 수 있음
