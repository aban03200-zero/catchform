# CatchForm Daily Worklog

이 파일은 CatchForm 작업 중 변경한 내용을 날짜별로 기록하는 문서입니다.
앞으로 기능 수정, 배포 준비, 오류 수정, 성능 개선이 생기면 같은 형식으로 이어서 남깁니다.

## 2026-08-25

### 반영 내용

- `/form/[slug]` 공개 폼 조회를 매 요청 `no-store` 방식에서 60초 재검증 캐시로 변경해 Vercel Fast Origin Transfer 사용량을 줄이도록 최적화
- 단순 버전 확인 API(`/api/version`)에 짧은 CDN 캐시를 적용하고, 클라이언트에서 매번 cache-busting query를 붙이던 호출을 제거
- 폼 이미지 업로드 시 대표 이미지, 광고 이미지, 안내문구/질문 이미지 등을 자동 압축하도록 추가해 새로 업로드되는 이미지의 전송량을 줄이도록 개선
- QR 방문 위치/스캔 분석은 정확한 집계가 필요하므로 `/api/geo` 방문 추적 방식은 유지
- 교육과정을 나중에 연동하더라도 기존 제출 응답의 `program_id`가 현재 연결된 교육과정으로 보강되도록 자동 동기화 로직 추가
- `applications`, `company_applications` 양쪽 응답 테이블 모두 현재 폼 ID 기준으로 교육과정 연결값을 갱신하도록 처리
- 누락되어 있던 2026년 7월 중순 이후 작업 내역을 커밋 기준으로 `docs/catchform-daily-worklog.md`에 날짜별로 보강

### 확인 필요

- 공개 폼 설정 변경은 최대 60초 뒤 운영 페이지에 반영될 수 있음
- 기존에 이미 저장된 큰 base64 이미지는 자동으로 작아지지 않으므로, 트래픽이 많은 폼의 이미지는 다시 업로드해야 최적화 효과가 큼
- 교육과정 사후 연동은 `form_id`가 남아 있는 응답만 안전하게 연결할 수 있으며, 오래된 데이터 중 `form_id`가 없는 row는 별도 식별 기준이 필요함

## 2026-08-06

### 반영 내용

- 폼 운영 기간을 단일 기간 1개가 아니라 여러 개의 운영 일정으로 설정할 수 있도록 확장
- 각 운영 일정은 `기간` 또는 `단일 날짜`로 선택해 추가할 수 있게 하고, 설정된 일정 중 하나라도 현재 날짜에 포함되면 폼 접근/제출이 가능하도록 변경
- 교육과정 상세 정보에서 교육기간, 모집기간 같은 일정을 여러 개 등록할 수 있도록 확장
- 교육과정 일정 항목에 관리용 이름을 입력할 수 있게 하고, 폼에 날짜가 반영될 때 해당 이름이 함께 표시되도록 변경
- 교육과정 일정 라벨은 날짜 왼쪽에 medium 굵기로 표시되도록 UI 조정

### 확인 필요

- 여러 운영 일정이 있는 폼은 설정한 일정 밖의 날짜에는 폼을 볼 수 없거나 제출할 수 없음
- 단일 날짜 일정은 해당 날짜 하루 전체를 운영 가능 시간으로 해석함

- 공유 버튼이 모두 꺼져 있을 때 완료 모달의 타이틀과 확인 버튼 간격이 너무 좁아 보이지 않도록 모달 여백을 조정
