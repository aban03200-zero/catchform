# 알림톡 템플릿 등록 안내 (접수 안내용)

작성: 2026-11-12 · 카카오 비즈니스에 템플릿을 등록하는 담당자용

## 등록 순서

1. **카카오 비즈니스 채널 ↔ 알리고 연동** — 채널이 연동되어 있어야 템플릿을 등록할 수 있습니다
2. **템플릿 등록** — 아래 본문을 그대로 붙여넣기
3. **검수 요청** — 영업일 2~5일 소요
4. **승인되면** 템플릿 코드와 본문을 캐치폼 설정에 입력

## 템플릿 본문 (이걸 그대로 등록)

템플릿 코드는 `catchform_apply_01` 로 하시면 됩니다.

```
#{고객명}님, 신청이 정상 접수되었습니다.

■ 과정명 : #{과정명}

담당자 확인 후 개별적으로 안내드릴 예정입니다.
접수 내용 확인이 필요하시면 본 채널로 문의해 주시기 바랍니다.
```

**변수는 2개뿐입니다.** 변수가 적을수록 승인이 잘 나고, 폼마다 설정할 일도 줄어듭니다.

### 왜 `#{과정명}` 을 변수로 두나요

템플릿 심사에 며칠이 걸려서 **과정마다 템플릿을 따로 만들 수 없습니다.**
`#{과정명}` 을 변수로 두면 **템플릿 하나를 모든 폼에서 돌려 쓸 수 있습니다.**
캐치폼에서 폼마다 과정 이름만 적어 넣으면 됩니다.

### 버튼 (선택)

넣는다면 **채널 추가** 버튼 하나만 권합니다. 웹링크 버튼은 주소가 고정이라 폼마다 다르게 쓸 수 없습니다.

- 버튼명: `채널 추가`
- 버튼 유형: `채널 추가 (AC)`

버튼을 등록했다면 **캐치폼 설정에서도 똑같이 추가**해야 합니다. 템플릿과 버튼이 다르면 발송이 거부됩니다.

## 승인 잘 받는 요령

알림톡은 **정보성 메시지만** 보낼 수 있습니다. 반려 1순위 원인이 광고성 문구입니다.

**넣으면 안 되는 것**

- 「지금 신청하세요」, 「선착순」, 「무료」, 「할인」, 「이벤트」 같은 권유·홍보 문구
- 신청하지 않은 다른 과정 소개
- 이모지, 과도한 특수문자

**넣어도 되는 것**

- 접수 사실, 접수한 과정 이름, 다음 절차 안내, 문의 방법

지금 초안은 **접수 확인만** 담고 있어 통과 가능성이 높습니다.

## 승인된 뒤 캐치폼에 넣을 것

관리자 화면 → 폼 열기 → **설정 › 접수 안내 알림톡**

| 입력칸 | 넣을 값 |
|---|---|
| 템플릿 코드 | `catchform_apply_01` |
| 알림톡 제목 | `접수 안내` |
| 템플릿 본문 | **승인된 본문을 그대로 복사해서 붙여넣기** |
| `#{고객명}` 연결 | 이름을 받는 질문 (예: `성함`) |
| `#{과정명}` 연결 | `직접 입력` 을 고르고 과정 이름 입력 |

> **본문은 승인받은 것과 띄어쓰기·줄바꿈까지 똑같아야 합니다.**
> 한 글자라도 다르면 카카오가 발송을 거부합니다. 반드시 복사해서 붙여넣으세요.

붙여넣으면 캐치폼이 `#{...}` 자리를 자동으로 찾아 연결 목록을 만들어 줍니다.
연결이 하나라도 비어 있으면 **발송하지 않고** 응답 상세에 사유를 남깁니다.

## 카카오톡을 안 쓰는 사람은

**「알림톡이 안 가면 문자로 대신 보내기」** 가 기본으로 켜져 있습니다.
카카오톡 미사용자나 채널 차단자에게는 같은 내용이 문자로 나갑니다. 끄지 마세요.
